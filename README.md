# Simple Address Book

A beginner-friendly C program that stores contact names and phone numbers while it is running.

## Features

- Add a contact
- Show all contacts
- Search for a contact by exact name

Contacts are stored in an array and are cleared when the program exits.

## Build and run

```sh
gcc address_book.c -o address-book
./address-book
```

On Windows, run `address-book.exe`.
